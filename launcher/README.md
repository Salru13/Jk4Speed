# Jk4Speed launcher UI

The front end of Jk4Speed (NFS Most Wanted 2005 on PS4). Three main screens, as in JkFlow: **PLAY**, **PATCH** and **SETTINGS** (FRAME RATE 30/60, SHOW FPS / MS, MODS, CONTROLS, SAVE GAMES, LOGS & SUPPORT, ABOUT), plus the loader and the "game didn't start" screen. Every screen carries the release badge top right. Players bring their own NFS Most Wanted PC v1.3 Black Edition; the launcher never ships game files. Official source: https://github.com/Salru13/Jk4Speed. It is UI and file logic only. It calls no PS4 API and does not touch Wine, DXVK or the game patches; the title plugs it in through one table of service callbacks (`jk_frontend_run`, see `INTEGRATION.md`).

## Layout

| Path | What |
|---|---|
| `src/jk_ui.*` | Software renderer: fills, slanted plates, glyph text. BGRX frame. |
| `src/jk_art.*` | Our own art in code: the dusk city, the JK4SPEED wordmark, pad glyphs, checklist icons, the loader's traffic streaks. |
| `src/jk_screens.*`, `jk_strings.h` | The screens as pure drawing from a model; every player-visible text. |
| `src/jk_loader.*` | The loader drawn while Wine starts. |
| `src/jk_frontend.*` | The state machine, the run loop and the `JkServices` seam. |
| `src/jk_patcher.*`, `jk_manifest.*` | Check, install, verify and restore our files in the game folder; the allow-listed package manifest. |
| `src/jk_support.*` | Support bundle (`/data/Jk4Speed/Logs/support`) and the launcher's own log. |
| `src/jk_layout.*`, `jk_config.*`, `jk_seed.*` | The `/data/Jk4Speed` folder layout (game folder found in any letter case, r3 state moved aside), the ini and profile composer (SHOW FPS / MS, ENABLE LOGS), and the Wine prefix seed import. |
| `src/jk_pace.*` | FRAME RATE: `DXVK_PS4_NFS_PACE=30|60` in `[jk4speed]` of `<game_dir>/jk4speed-dev.ini`, digits only (both accepted hashes kept). |
| `src/jk_saves.*`, `jk_md5.*` | SAVE GAMES: `/data/Jk4Speed/Saves/NFS Most Wanted`; import (PC folder, profile folders, zip/7z) with every save checked (header, 3 EA-CRCs, MD5), collisions, atomic swap; export; player-name rename (`docs/launcher/2026-11-23-save-format.md`). |
| `src/jk_keyboard.*` | The pad-driven on-screen keyboard (from the Blur launcher; the PS4 system keyboard does not work in our Wine titles). |
| `src/jk_modset.*`, `jk_modset_catalog.inc` | The mod set: X360 Stuff Pack / Upscaled HUD / HD road archives from the drop folders, any combination, pristine copies, rebuild in staging, checks, journal swap, recovery (`docs/launcher/MODS.md`). The catalog is generated by `title/author_deltas.py`. |
| `src/jk_archive.h`, `jk_zip.c`, `jk_7z.c`, `jk_inflate.*`, `jk_lzma.*` | Reading zip (stored, deflate) and 7z (LZMA, LZMA2) on the console. |
| `src/jk_delta.*`, `jk_ups.*`, `jk_jdlz.*` | JKD1 deltas, UPS patches, the game-exact JDLZ counter check. |
| `src/jk_elfdigest.*` | The load-segment digest that recognises our DXVK server raw or unwrapped by FTP. |
| `src/jk_fs.*`, `jk_sha256.*` | Atomic, verified file helpers; SHA-256. |
| `devtools/jk_devhook.*` | The title's console test hook, off unless `/data/Jk4Speed/devtools/enable` exists when the launcher opens: PAD/RELEASE/SNAP/STATE over the bench remote-control protocol v1 in `/data/Jk4Speed/devtools/` (PC side: `tools/console/launcher_step.py`). Not part of the launcher core. |
| `tools/bake_font.c`, `tools/bake_assets.sh` | Bake the Ubuntu Sans glyph atlases into `build/gen` (not committed). |
| `tools/make_manifest.py` | Writes `jk4speed-files/manifest.txt` for a package. |
| `tools/pack_goldens.py` | Packs the rendered previews into `golden/*.png`. |
| `assets/font/` | Ubuntu Sans variable fonts and `LICENCE.txt` (Ubuntu Font Licence 1.0). Taken from the build host's `/usr/share/fonts/truetype/ubuntu/`: `UbuntuSans-VF.ttf` sha256 `37e90bba…fe40`, `UbuntuSans-Italic-VF.ttf` sha256 `603f7a4b…d3df`. |
| `golden/` | `goldens.txt` (pixel hash per screen) and the PNG of each. |
| `tests/` | Host tests. |

## Build and test (WSL)

```bash
launcher/tests/run.sh                 # everything (C tests under ASan + UBSan, then the .sh/.py tests)
launcher/tests/run.sh test_patcher    # one test
launcher/tests/run.sh preview_ui      # art previews in build/preview
```

FreeType comes from the existing Wine build tree; override with `FREETYPE_INCLUDE` and `FREETYPE_LIB`.

After a deliberate visual change:

```bash
JK_UPDATE_GOLDEN=1 launcher/tests/run.sh test_golden
python3 -I launcher/tools/pack_goldens.py
```

## For players

- **Player guide and FAQ:** `docs/launcher/README-player.md`, `docs/launcher/FAQ.md` (shipped in the package under `docs/`).
- **Mods:** `docs/launcher/MODS.md` (download each mod from its author, put it unchanged in `/data/Jk4Speed/Mods` or `USB:/Jk4Speed`, turn each on or off in SETTINGS > MODS, press PATCH; any mix works).
- **Save games:** `docs/launcher/save-games.md` (saves live in `/data/Jk4Speed/Saves`; copy your PC save from `Documents\NFS Most Wanted` to `USB:/Jk4Speed/saves/` → SETTINGS → Save games → Import; △ Player name renames a profile).
- **Credits:** About > □ Credits (`assets/CREDITS.txt`, shipped as `jk4speed-files/about/CREDITS.txt`).
