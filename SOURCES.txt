JK4SPEED for PS4: where the source is
=====================================

JK4SPEED 1.0 (package IV0000-JKSP00001_00-JK4SPEED00000001).

This repository
  launcher/   the JK4SPEED launcher (PLAY / PATCH / SETTINGS, the mod
              patcher, save tools, the release badge), LGPL-2.1-or-later
  title/      how the title is built from the Wine PS4 runtime and the
              launcher, and how the package is made and signed
  probe/, templates/   pre-flight probe, profile and registry templates

The Wine PS4 runtime
  JK4SPEED uses the Wine PS4 runtime of JkFlow 1.00 (LGPL-2.1-or-later).
  Its source, with the changes, is published with JkFlow:
    https://github.com/Salru13/JkFlow (tag v1.00): wine/, title/, mesa/

The native DXVK client (d3d9.dll)
  Our build of DXVK 1.10.3 for the PS4 renderer path. DXVK is under the
  zlib licence (LICENSES/DXVK-zlib.txt), which does not require the source
  of changes to be published. It is not published at this time.

Upstream projects
  Wine:  https://gitlab.winehq.org/wine/wine
  DXVK:  https://github.com/doitsujin/dxvk
  Mesa:  https://gitlab.freedesktop.org/mesa/mesa

Shipped mod tools (unchanged builds, their own licences in LICENSES/)
  Ultimate ASI Loader (dinput8.dll):  https://github.com/ThirteenAG/Ultimate-ASI-Loader
  Xidi (Xidi.32.dll):                 https://github.com/samuelgr/Xidi
  Xenon Effects:                      https://github.com/xan1242/NFSMW_XenonEffects

Not included
  Need for Speed: Most Wanted and the mods (Xbox 360 Stuff Pack, Upscaled HUD,
  HD Road Textures) are not part of this repository or the package. The player
  downloads them from their authors.
